# CasaVPN

A home VPN on a Raspberry Pi that you can rebuild in an afternoon, and an iPhone app
to manage it. CasaVPN is open source (MIT). The code is at
[github.com/zaitsew/casavpn](https://github.com/zaitsew/casavpn).
