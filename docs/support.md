# CasaVPN Support

CasaVPN is an admin console for a VPN server that you run yourself. It is open source, and
support happens in public on GitHub.

## Get help

1. Read the [FAQ](FAQ) and the [iPhone app guide](APP).
2. Search the [open and closed issues](https://github.com/zaitsew/casavpn/issues).
3. If you find nothing, [open a new issue](https://github.com/zaitsew/casavpn/issues/new).
   Say which iPhone and iOS version you use, which app version, and what
   you expected to happen.

**Issues are public.** Never post passwords, API tokens, relay tokens, pairing codes or
the address of your server. Remove them from screenshots and logs first. For a security
problem, follow [SECURITY.md](https://github.com/zaitsew/casavpn/blob/main/SECURITY.md)
instead of opening a public issue.

## Common questions

**Is CasaVPN a VPN?** No. It manages a VPN server that you own. It does not connect your
iPhone to a VPN and does not route traffic.

**I have no server. Can I try the app?** Yes. Open demo mode on the first screen. It uses
sample data and needs no server.

**The app cannot reach my panel.** The panel is usually closed to the internet. Connect
your iPhone to your home network, to your VPN or to your private network, then try again.

**I get no alerts.** Check that notifications are allowed for CasaVPN in iOS Settings, that
the relay address and token are right, and press Settings, Send test alert.

**What data does the app collect?** None for the developer. See the
[privacy policy](privacy).
